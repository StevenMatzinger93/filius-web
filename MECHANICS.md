# Mechanik-Blatt

Werte und Regeln aus dem Original **Filius 2.14.0**, die der Bau verwendet, mit ihrer Fundstelle.
Maschinenlesbare Fassung: `mechanics.json`. Im Code liegen die Konstanten in
`src/engine/model/original.ts`.

## 1. Was das Programm ist (native Dekompilierung, Ghidra)

| Programm                                                                          | Funktion (Adresse)            | Was der Code tut                                                                                                                                                                | Folge für den Bau                            |
| --------------------------------------------------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `Filius-Setup_with-JRE-2.14.0.exe` (Nullsoft Install System v2.50, 73 Funktionen) | `entry` @ **0x40310d**        | liest die Befehlszeile: `/S` (still), `/NCRC` (ohne Prüfsumme), `/D=` (Zielordner); legt Temp-Ordner an; ruft die Paketprüfung                                                  | Installer, keine Simulationslogik            |
|                                                                                   | `FUN_00402c38` @ **0x402c38** | sucht im eigenen Dateiende den NSIS-Kopf (Signatur «NullsoftInst», 0xDEADBEEF), prüft die CRC; Fehlertext «Installer integrity check has failed» @0x409038                      | Programmdateien liegen komprimiert im Anhang |
|                                                                                   | `FUN_00405bc3` @ **0x405bc3** | setzt Pfade aus Variablen zusammen, u. a. aus `HKLM\Software\Microsoft\Windows\CurrentVersion` und Shell-Ordnern                                                                | nur Installationspfade                       |
| `Filius.exe` (Launch4j-Starter, aus dem Anhang)                                   | `FUN_004034b3` @ **0x4034b3** | baut die Java-Startzeile: `-classpath "…"` aus der Ressource (Bibliotheken in `lib/`), Hauptklasse **`filius.Main`** (Ressource @0x427ff8), Laufzeit `java-runtime` (@0x427fd0) | die eigentliche Logik steckt in `filius.jar` |
|                                                                                   | `FUN_00402e1f` @ **0x402e1f** | berechnet `-Xms`/`-Xmx` aus dem freien Arbeitsspeicher (`GlobalMemoryStatusEx`)                                                                                                 | ohne Bedeutung für die Web-App               |

Die Simulationslogik ist Java-Bytecode. Deshalb sind die Fundstellen unten **Klasse.Methode @ Bytecode-Offset**
in `filius.jar`. Gelesen wurden sie mit dem Java-Dekompiler von Craft Anything (Disassembly und Pseudo-Java).
